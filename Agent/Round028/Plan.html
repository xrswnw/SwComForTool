二、需求 1 设计: 握手启用按钮

1.1 现有 enableFuncButtons 逻辑

协议字段:m_verSwEdit 形如 SW:ZLR5401_V1.0 或 SW:SCCD_V1.0。需从 : 后取子串判断前缀。

1.2 新增 enableSuppBySw(QString swText) 函数

// swText 形如 "ZLR5401_V1.0" 或 "SCCD_V1.0" (不含 "SW:" 前缀, 已在 onHandshakeResponse 提取)
// 规则: 前缀匹配
if (swText.startsWith("ZLR5401")) {
    m_sccdBtn->setEnabled(false);   // SCCD 灰
    m_sccdBtn->setChecked(false);   // 防止已勾选
    m_sccdBox->setVisible(false);
    m_zlrBtn->setEnabled(true);
    m_zlrBtn->setChecked(true);      // 自动展开 ZLR5401
} else if (swText.startsWith("SCCD")) {
    m_sccdBtn->setEnabled(true);
    m_sccdBtn->setChecked(true);     // 自动展开 Sccd
    m_sccdBox->setVisible(true);
    m_zlrBtn->setEnabled(false);
    m_zlrBtn->setChecked(false);
} else {
    // 其它 / 空 - 全禁用
    m_sccdBtn->setEnabled(false);
    m_sccdBtn->setChecked(false);
    m_sccdBox->setVisible(false);
    m_zlrBtn->setEnabled(false);
    m_zlrBtn->setChecked(false);
}

1.3 触发点

  • 握手成功后 (onHandshakeResponse 已解析 SW): 调用 enableSuppBySw
  • 断开重置 (resetUiToInitialState): 调用 enableSuppBySw("") 全禁用

1.4 边界

  • 握手是单独的 QPushButton (m_funcHandshakeBtn), 与 Supported Devices 按钮独立性: 握手按钮始终启用, 握手后才去 enableSuppBySw.
  • 连接断开: 按钮回到全禁用.
  • 已测试其它 ZLR 命令 (如 SELFTEST 0x0F) 不受影响, 因 m_transport 已通过握手才打开.

三、需求 2 设计: ZLR5401 "系统"类目合并

2.1 合并 Tab 选项

需要你确认方案:

  1. 方案 A: 自检 + RGB 合成一个 Tab "系统", Tab 内部分两区(自检区/系统区)? - 实施简单但一个 Tab 内塞两组不相关功能。
  2. 方案 B: 自检 和 RGB 改为两个分组 GroupBox 并排在同一层, 不用 TabWidget 分开; 加一个独立"系统"区域显示在 TabWidget 之外? - 与现有 ZLR 主体结构(电机/UHF/AM/开锁器 用 Tab, 自检/RGB 也是 Tab)冲突。
  3. 方案 C: 自检 Tab 和 RGB Tab 位置交换/重排, 同处一区域但保留各自 Tab 标题? - 没真正合并。
  4. 方案 D: 把自检 + RGB 整合为新"系统" Tab, 内部左右两列(左:自检, 右:RGB 控制), 都是同一类"系统相关"。- 推荐: 语义清晰(都是系统级/硬件状态) + 界面紧凑。

默认采用方案 D (推荐), 如要 A/B/C 请回复。

去掉 m_zlrSelfOut(QTextEdit 输出区)。

保留并升级 m_zlrSelfErrBitsLabel 和 m_zlrSelfDiagLabel 为 QTableWidget(2 列 × N 行), 或用纯 QLabel 表格布局(更轻量)。
