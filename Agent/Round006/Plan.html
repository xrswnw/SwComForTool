需求2 · 串口状态联动锁定 逻辑

变更点

  • 串口未打开：功能区全禁用（握手按钮、地址框、更新按钮）、日志区禁用（清空/保存可用）、发送区全禁用

  • 校验版本通过 (m_funcUnlocked=true)：解锁功能区其余组件（更新固件、通信调试按钮）
  • 功能区版本信息框（地址框 m_verTopEdit、版本显示 m_verBottomEdit）在功能栏中居中（用 stretch 撑开两侧）
  • 调整 updateConnectionState() 中各 widget 的 setEnabled 逻辑
  • 调整 enableFuncButtons()，校验通过后额外启用通信调试按钮

涉及文件

需求5 · 通信调试面板 UI+逻辑核心

面板布局（点击"通信调试"后，在功能栏下方独立展开）

  • 上行：地址输入框(QLineEdit) · 功能码输入框(QLineEdit) · 超时输入框(QSpinBox, 默认3000ms) · 打包按钮 + 旁边文字展示组帧Hex结果
  • 下行：宽的参数输入框(QLineEdit, Hex空格分隔, 可为空)，参数长度限制：协议帧 Data字段最大长度 = 65535 - 1(FC) - 4(CRC) ≈ 65530 字节，实际限制取 512 字节
  • 关闭按钮：面板右上角 × 按钮，可单独关闭面板

打包逻辑

  • 读取地址(1字节)、功能码(1字节)、超时时间、参数(Hex解析)
  • 调用 ProtocolParser::makeFrame(devAddr, fc, paramData) 组帧
  • 清空发送区输入框，将组帧结果填入发送区
  • 在打包按钮旁文字展示组帧的Hex

实现方式

  • 在功能栏 QGroupBox 下方插入 m_debugPanel (QFrame, 带边框)，默认隐藏
  • 点击"通信调试" → m_debugPanel->setVisible(true)，关闭按钮 → setVisible(false)
  • 面板为独立区域，不影响功能栏自身布局

涉及文件

  • src/MainWindow.h — 新增 m_debugBtn, m_debugPanel, m_debugAddrEdit, m_debugFcEdit, m_debugTimeoutSpin, m_debugParamEdit, m_debugPackBtn, m_debugFrameLabel
  • src/MainWindow.cpp — setupUI 面板构建、onDebugPack 槽函数

需求10 · Windows打包方案 (Win10/Win11) 构建重要

方案：MinGW 静态链接 + windeployqt

A. 交叉编译方案（在Mac上编译Windows exe）

交叉编译工具链配置复杂且Qt对MinGW交叉编译支持有限，不推荐。

B. Windows原生编译 + 部署（推荐）

前置条件

  • Windows 10/11 64位系统
  • 安装 Qt 6.8.3 MSVC 2022 64-bit（从 Qt官方安装器 或 aqtinstall）
  • 安装 Visual Studio 2022 Build Tools（或 Community Edition），含 C++ 桌面开发工作负载
  • 安装 CMake 3.20+

编译步骤

# 1. 打开 "x64 Native Tools Command Prompt for VS 2022"

# 2. 配置 CMake（指向Qt MSVC路径）
cmake -S C:\ComforTool -B C:\ComforTool\build ^
      -DCMAKE_PREFIX_PATH="C:/Qt/6.8.3/msvc2022_64" ^
      -DCMAKE_BUILD_TYPE=Release

# 3. 编译
cmake --build C:\ComforTool\build --config Release

# 4. 部署Qt依赖（复制Qt DLL等）
cd C:\ComforTool\build\Release
C:\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe ComforTool.exe ^
      --dir C:\ComforTool\deploy ^
      --release ^
      --no-translations ^
      --no-opengl-sw

# 5. 复制可执行文件
copy ComforTool.exe C:\ComforTool\deploy\

# 6. 复制串口模块DLL（windeployqt不自动处理SerialPort）
copy C:\Qt\6.8.3\msvc2022_64\bin\Qt6SerialPort.dll C:\ComforTool\deploy\

# 7. 如有自定义icon.rc，确保已编译嵌入exe

# 8. 打包
cd C:\ComforTool\deploy
..\issue\pack.bat
# 生成 issue\ComforToolV1.1_Win64.zip

pack.bat 脚本内容

@echo off
setlocal enabledelayedexpansion

:: 从CMakeLists.txt提取版本号
for /f "tokens=2,3 delims= )" %%a in ('findstr /c:"project(ComforTool VERSION" ..\CMakeLists.txt') do set VER=%%a
set VER=%VER: =%
set PKGNAME=ComforTool%VER%_Win64

:: 清理并打包
if exist "..\issue\%PKGNAME%.zip" del "..\issue\%PKGNAME%.zip"
powershell -Command "Compress-Archive -Path '.\*' -DestinationPath '..\issue\%PKGNAME%.zip'"
echo 已生成: ..\issue\%PKGNAME%.zip
pause

Win10/Win11 兼容性说明

  • MSVC 2022 编译的程序依赖 vcruntime140.dll 等 Visual C++ 运行时。建议在 deploy 目录中附带 VC++ Redistributable 安装包，或在 pack.bat 中复制 DLL：
:: 复制 VC++ 运行时 (VS 2022 → 14.40.x)
copy "C:\Program Files\Microsoft Visual Studio\2022\Community\VC\Redist\MSVC\14.42.34433\x64\Microsoft.VC143.CRT\*.dll" .\
  • windeployqt 自动处理 Qt6Core、Qt6Gui、Qt6Widgets、plugins 等
  • Qt6SerialPort 需要手动复制（上面步骤6）
  • 打包后在 干净的 Win10/Win11 上测试，确认无缺失 DLL
  • 如需 单文件绿色版，可使用 Enigma Virtual Box 将所有 DLL 打包为单 exe（非必须）

五、风险与备注

需求7（序号缺失）原始文档中不存在，视为预留未使用。
通信调试面板为独立区域，在功能栏下方展开关闭，不影响功能栏内部布局。
Windows打包需在Windows物理机（或VM）上操作，macOS无法直接生成Win exe。pack.bat 作为参考脚本提供。
所有删除文件遵循规则移至 TrashCan/，不使用 rm -f。
