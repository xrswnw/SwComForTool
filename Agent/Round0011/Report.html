遇到的关键问题与解决

1. macOS root GUI 不可行

现象: AEWP 启动 root GUI 进程在 QCoreApplication 构造时 fatal (缺少 WindowServer 访问)

解决: 架构改造为 普通 GUI + root daemon + Unix Socket IPC。AEWP 仅用于启动 daemon (无 GUI), GUI 永远以普通用户跑。

2. DEVICE_INFO 响应 FC 不符合协议

现象: 设备响应 FC=0x86, 协议应为 0x07^0xFF=0xF8

解决: 兼容判断 fc==0x86 || fc==0xF8

3. 设备合并回传多帧

现象: 单 HID 包包含 HANDSHAKE 帧(23B) + DEVICE_INFO 帧(23B) + 后续 data 字节

解决: parseFrame 容忍 CRC 错误 (设备 CRC 计算范围可能含附加 data), 解析循环按字节扫描找 0x53 0x77 头, 取完整 buffer 作为 device info data

4. 启动时序 EP stall

现象: 第一次 open 后立即发握手, 设备未响应

解决: open 中加 warm-up (500ms sleep + dummy write + 300ms sleep), HidServer/HidManager 共用

5. dataReceived 递归 emit 死机

现象: HidClient readAll emit dataReceived → lambda 同步调 onReadyRead → readAll → emit → 递归

解决: setTransportSignals connect 用 Qt::QueuedConnection
