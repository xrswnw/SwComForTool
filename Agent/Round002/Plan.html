1
MainWindow 重构为三层布局

按照新需求重构界面：MainPage 1280×960，顶部握手栏、中部功能栏（预留）、底部日志栏。

  • 窗口初始大小改为 1280×960，用户可调整 UI
  • 窗口标题改为 "ComforTool" UI
  • 重构 setupUI()：移除现有布局，改为三层垂直布局 重构
  • 握栏：水平排列 Com口选择 → 波特率 → 数据位 → 停止位 → 校验 → 握手按钮 UI
  • 功能栏：添加预留区域 QGroupBox，暂放置占位提示 UI
  • 日志栏：分为接收区上方 + 发送区下方，保留原有串口助手功能 UI
握手按钮与原"打开/关闭"按钮合并：点击握手=打开串口，再次点击=关闭。串口选择改为固定Com口（下拉框仅显示cu.usbserial/com口设备）。

串口选择优化 - 固定Com口

串口枚举过滤：仅显示COM风格的串口设备（如cu.usbserial-*），握手按钮替代原打开/关闭按钮。

  • refreshPorts() 过滤仅显示 usbserial / cu.usbmodem 等COM口设备 Qt
  • 握手按钮：未连接时显示"握手"（点击打开串口），已连接时显示"断开"（点击关闭） UI
  • 移除原有"刷新"按钮（串口列表在窗口初始化时自动枚举，用户也可手动刷新） 重构
3
Win10 兼容方案

确保代码在 Win10 上可编译运行，CMake 配置跨平台兼容。

  • CMakeLists.txt 添加跨平台处理：Windows 下自动链接 Qt6Widgets/SerialPort（无需手动设置前缀） 跨平台
  • CMAKE_PREFIX_PATH 改为条件判断：仅在非Windows且本地Qt存在时设置 跨平台
  • 串口名称跨平台处理：macOS 用 cu.usbserial*，Windows 用 COM* 跨平台
  • 串口枚举过滤逻辑按平台分支 跨平台
当前无需在Win10上实际编译，仅确保代码和构建脚本兼容。Win10 实际编译需在 Windows 环境下安装 Qt6 和 MSVC 后执行。
