1. 需求分析

#需求当前问题修改方向

但FC=0x04传输失败仍会continue触发3次重试(从头擦除+写入)		 传输失败也不重试，直接结束升级
2 地址显示框在版本信息GroupBox内居中 m_verTopEdit设置了setAlignment(Qt::AlignCenter)文字居中，但控件本身靠左显示(MaximumWidth=70，GroupBox宽约140+，左侧留白) 在verLayout上设置setAlignment(Qt::AlignCenter)让控件居中，或改用Container居中

Layer=1(APP): 显示 "AD01 V1.0 AD_V1.3"

2. 修改详情

2.1 需求1：升级失败不重试

当前逻辑：

for (attempt = 1; attempt <= 3; ++attempt) {
    FC=0x03 擦除...失败 → continue (重试)
    FC=0x04 传输...失败 → transferFailed=true; break → continue (重试)
    FC=0x05 校验...失败 → endUpgrade(false); return (不重试 ✓)
}

修改后逻辑：

FC=0x03 擦除...失败 → endUpgrade(false); return (不重试)
FC=0x04 传输...失败 → endUpgrade(false); return (不重试)
FC=0x05 校验...失败 → endUpgrade(false); return (不重试,已实现)
具体改动：
  • 移除MAX_RETRIES重试循环，改为线性顺序执行
  • FC=0x03超时/失败 → endUpgrade(false); return;
  • FC=0x04传输失败 → endUpgrade(false); return;
  • 保留: FC=0x06执行后无响应→3秒后握手检查Layer的逻辑(这是正常等待，不是重试)

2.2 需求2：地址输入框居中

当前：m_verTopEdit MaximumWidth=70，GroupBox约140px，控件靠左。

修改：

// verLayout中两个控件都使用居中对齐
verLayout->setAlignment(m_verTopEdit, Qt::AlignCenter);
verLayout->setAlignment(m_verBottomEdit, Qt::AlignCenter);

2.3 需求3：版本信息按Layer区分显示

显示规则：

Layer上栏(地址)下栏(版本)示例
0 (BOOT) 设备地址(不变) BOOT版本 + 硬件版本 BOOT_V1.0 AD_V1.3
1 (APP) 设备地址(不变) 项目名+软件版本 + 硬件版本 AD01 V1.0 AD_V1.3

变更：

  • 握手阶段获取Layer
  • FC=0x07返回后，根据devInfo.layer分别组装版本字符串
  • Layer=0: "BOOT_" + bootVersion + " " + hwVersion
  • Layer=1: projectName(或"AD01") + " " + swVersion + " " + hwVersion
  • verBottomEdit宽度适当增大(140→180)以容纳更长字符串
