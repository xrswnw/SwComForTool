2. 修改详情

2.1 升级执行失败不重试

场景：FC=0x06升级执行后，设备仍在BOOT(Layer=0)，说明固件虽写入完成但无法启动，重复同样的固件没有意义。

改动：

  • FC=0x06响应Result!=0x00 → endUpgrade(false); return;（原为continue重试）
  • FC=0x06后握手Layer=0 → endUpgrade(false); return;（原为continue重试）
  • FC=0x06后握手失败 → endUpgrade(false); return;（同上）

保留：FC=0x03擦除失败、FC=0x04传输失败的重试逻辑不变(最多3次)。

2.2 地址输入框居中

改动：

verLayout->setAlignment(m_verTopEdit, Qt::AlignCenter);
verLayout->setAlignment(m_verBottomEdit, Qt::AlignCenter);

m_verTopEdit和m_verBottomEdit控件在版本信息GroupBox内水平居中，不再靠左。verBottomEdit最大宽度从140调整为180以容纳更长的版本字符串。

2.3 版本信息按Layer区分显示

Layer显示格式示例
0 (BOOT)BOOT_ + bootVersion + + hwVersionBOOT_V1.0 AD_V1.3
1 (APP)hwVersion + + swVersionAD_V1.3 V1.0

同时移除了重复的version string赋值块（原代码有两段重复赋值逻辑）。
