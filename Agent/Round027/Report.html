  • 开锁器 Tab 新增解锁区 GroupBox: 期望 EPC 输入框 + demagCnt SpinBox(默认 0) + 解锁按钮(主操作色)。

六、关键技术点 & 修复记录

  1. PMF connect 必须 sender 是派生类指针: m_zlrLockerWait 不能声明为 QDialog*, 必须为 LockerWaitDialog*, 否则 QObject connect 重载 SFINAE 拒绝. (编译错误 "cannot convert from base class pointer 'QDialog *' to derived class pointer 'const LockerWaitDialog *'").
  2. CANCEL 竞态兜底: 用户点停止 → 发 CANCEL → 协议 §五.5 立即回 OK + 异步完成回降 + 最终 ONE_SHOT 原帧带 endReason=6 ABORTED. 若 ONE_SHOT 原帧不来(链路断), 1s 兜底定时器强关等待框.
  3. 请求帧顺序: §五 协议顺序为 cmd+tmo+hold+epcLen+epc+(demagCnt). demagCnt 可缺省, 我实现里总带上(默认 0).
  4. 响应解析顺序: sendZlrSubCmd 已剥 cmd+err, outPayload = [endReason, epcLen, epc, rise(2), lower(2), demagDone, retreat(可选)]. err 单独从 sendZlrSubCmd 结果外推 (成功=0, 否则 err=协议默认 0xFF).
  5. ONE_SHOT 超时: sendZlrSubCmd 默认 3000ms 不够, 传 60000ms 涵盖保持期 30s+回降+缓冲.
  6. 5s 轮询超时: GET_PROGRESS 用 3000ms (设备响应快, 不阻塞 UI).
