ComforTool - Round001 执行计划

基于Qt的串口通信桌面程序 · 初始搭建

1
备份系统搭建

创建备份文件夹并完成初始全量备份，建立变更日志机制。

  • 在 /Volumes/Untitled 1/Files/BackupArea/ 下创建 ComforTool/ 备份目录 备份
  • 将当前工程全量复制到备份目录 备份
  • 在备份目录中创建 ChangeLog/ 文件夹，用于记录变更日志 备份
  • 创建变更日志记录脚本 log_change.sh，每次工程文件变更时自动记录：时间、变更文件、变更类型、变更内容摘要 备份
  • 配置文件监听机制（使用 fswatch 或类似工具监控工程目录变更，触发备份同步和日志记录）备份
备份路径优先使用外置硬盘 /Volumes/Untitled 1/Files/BackupArea/ComforTool，已验证可访问。
2
工程基础设施

在根目录创建 TrashCan（回收站）、.claude 配置等基础结构。

  • 在工程根目录创建 TrashCan/ 目录，所有删除操作将文件移至此处而非彻底删除 安全
  • 创建 .claude/settings.json 配置文件，将常用权限预授权，避免执行中弹窗 配置
  • 创建 CLAUDE.md 项目说明文件，记录项目规则和约定 配置
删除策略：任何需要删除的文件统一移至 TrashCan/，保留原始路径结构以便恢复。
3
Qt 项目搭建

创建基于 CMake + Qt6 的桌面应用项目，配置串口通信依赖。

  • 确认本机 Qt6 安装情况，如缺失则通过 Homebrew 安装 Qt6 Qt
  • 创建 CMakeLists.txt，配置 Qt6 Core、Gui、Widgets、SerialPort 模块 Qt
  • 创建 src/ 源码目录结构 Qt
  • 编写 main.cpp 入口文件 Qt
  • 编写 MainWindow 主窗口类（.h / .cpp / .ui）Qt
  • 编写 SerialPortManager 串口管理类（.h / .cpp），封装 QSerialPort 的打开/关闭/收发逻辑 Qt
  • 配置构建目录 build/，执行首次 CMake 配置和编译，验证项目可构建运行 Qt
4
串口通信界面 & 功能实现

实现主窗口的串口选择、打开/关闭、数据收发功能。

  • UI设计：串口选择下拉框 + 刷新按钮 + 打开/关闭按钮 + 波特率选择 Qt
  • UI设计：发送区（文本输入 + 发送按钮 + hex发送选项）Qt
  • UI设计：接收区（文本显示 + hex显示选项 + 清空按钮 + 自动滚动）Qt
  • 功能实现：串口枚举与选择 Qt
  • 功能实现：串口打开/关闭，支持配置波特率/数据位/停止位/校验位 Qt
  • 功能实现：文本模式 & Hex 模式的数据收发 Qt
  • 功能实现：接收数据实时显示与自动滚动 Qt
  • 异常处理：串口断开检测、错误提示、自动重连提示 Qt
5
验证 & 报告

编译运行验证，同步最终备份，生成执行报告。

  • 完整编译项目，确保零错误零警告 Qt
  • 运行程序，验证窗口正常显示、串口枚举正确 Qt
  • 同步最终状态到备份文件夹，补齐所有变更日志 备份
  • 生成 Report.html 执行报告，记录所有操作、文件变更、最终项目状态 报告

优化建议：
1. 建议后续添加串口数据日志保存功能，可将收发数据导出为文件，便于调试分析。
