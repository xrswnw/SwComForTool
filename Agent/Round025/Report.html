二、ZLR5401 协议与 UI 对应（依据 App_Protocol.html）

Tab控件协议 (FC/subCmd)帧 data
电机
0x0A		 正转(CW) / 反转(CCW)MOVE 0x01[01, dir, steps 24bit LE]
角度(°) + 每转微步 → 换算 steps—steps = round(角度/360 × 每转微步)；0°→持续运行(steps=0)
设速度SPEED 0x03[03, hz 16bit LE]
设转矩TORQUE 0x04[04, pct]
停止STOP 0x02[02]
查询状态QUERY 0x05解析 state/fault/diag1/diag2/stepsDone
清除故障CLEAR 0x06[06]
UHF
0x0B		 开启/关闭OPEN 0x01 / CLOSE 0x02[01] / [02]
盘点INVENTORY 0x03[03]
查询QUERY 0x07解析 state/link/totalTags
取标签GET_TAGS 0x0A[0A, count=0] → 解析 EPC/rssi
功率输入 / 设配置SET_CONFIG 0x09[09, power,ant,crc,session,target,q]
读配置GET_CONFIG 0x08解析 power/ant/crc/session/target/q
（读/写标签 READ_TAG/WRITE_TAG 留待后续，见第三节）—
AM
0x0C		 读/写配置GET/ SET_CONFIG 0x01/0x02九参数(thr/hit/freq/delay/len/invert/sync/volt/mode)，16bit 高字节在前
查询QUERY 0x05解析 link
（GET/SET_PARAM 单参数读写留待后续）—
开锁器
0x0D		 配置清单(软标N)CONFIGURE 0x01[01, hardCnt0,0, softCnt 16bit LE]
追加硬标ADD 0x02[02, epcLen, epc..]
开始/取消START 0x03 / CANCEL 0x04[03] / [04]
查询QUERY 0x05解析 state/hm/sc/su
取事件GET_EVENT 0x07解析 code/EPC/hm/su/sc/hc
（CONSUME_SOFT 0x06 软标消耗留待后续）—

帧样例（正转 90°，每转 3200 微步，速度 1000）

SPEED:   makeFrame(0x0A, [03, E8 03])  →  53 77 01 00 08 00 0A 03 E8 03 [CRC32]
MOVE:    dir=0, steps=round(90/360×3200)=800=0x000320
         makeFrame(0x0A, [01, 00, 20 03 00])  →  53 77 01 00 0A 00 0A 01 00 20 03 00 [CRC32]
响应:    func=0x0A^0xFF=0xF5, data=[01, err(0=OK)]
