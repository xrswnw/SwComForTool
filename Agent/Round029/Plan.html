1.2 主窗口纵向栈与 LOG 显示不全的根因

mainLayout (QVBoxLayout, 6px 边距)
 ├ Handshake Area        (固定行)
 ├ Function Area         (固定行)
 ├ Tool                  (固定行)
 ├ Supported Devices     (固定行)
 ├ Version               (固定行)
 ├ Sccd Area             (m_sccdBox, 默认隐藏, 可展开)
 ├ ZLR5401 Area          (m_zlrBox, 默认隐藏, 可展开) ← 展开后占高最大
 ├ 通信调试面板           (默认隐藏)
 └ logSplitter (stretch=1): Exporting Area + Log Area

根因：m_zlrBox 的 6 个页内容全部为固定高度组合，Preferred 高度 ≈ 600~800px；上方 5 个区无高度上限，m_zlrBox 又未做尺寸约束（L1544-1545 显式设 Preferred）。最大化时若屏幕总高 < 上方栈最小高度和，logSplitter（stretch=1）被上方各区的 minimumSizeHint 挤压 → LOG 区只剩几行甚至不可见。另有：SCCD 与 ZLR 同时展开时更甚。

二、改造方案

D1 — UHF 控制区仅留 盘点 / 状态获取 / 天线检测
  • 控制区保留 3 按钮：m_zlrUhfInvBtn(盘点→onUhfInventory)、m_zlrUhfStatusBtn(读状态→onUhfGetStatus，即"状态获取")、m_zlrUhfAntBtn(天线检测→onUhfCheckAnt)，单行排列。
  • 隐藏 4 按钮：m_zlrUhfOpenBtn / m_zlrUhfCloseBtn / m_zlrUhfQueryBtn / m_zlrUhfGetTagsBtn — setVisible(false)，connect 与槽函数全部保留。
  • 周期(ms) spin 迁移：onUhfInventory 以 m_zlrUhfCycle 值为盘点超时参数（L2705），扫描区隐藏后用户无处可调 → 把周期输入行移入控制区（盘点按钮旁），不新增成员。
D2 — 读写区封禁不可用（可见但禁用）
  • rwBox 标题改为「读写（已封禁）」，m_zlrUhfReadBtn / m_zlrUhfWriteBtn setEnabled(false)，提示标签改为「读写功能暂时封禁」。
  • 选择可见+禁用而非隐藏：需求用词"封禁"意为存在但不可用，保留区块可见让用户知道功能存在；后续解封只需恢复 enable/文案，一行改动。
D3 — AM 仅留配置区
  • 保留：「配置」区（10 参数网格 + 读配置 / 写配置）。
  • 隐藏（代码保留只是不显示）：monBox(监控)、waveBox(波形)、AM 输出区 — setVisible(false)；成员（m_zlrAmQueryBtn 等）与槽函数不动。
  • 注意：AM 输出区隐藏后，写配置的回读结果显示走主 LOG 区（appendSystemLog 路径已有），不丢信息。
D4 — 开锁器仅留解锁 + 操作
  • 保留：「解锁」（UNLOCK_MULTI，唯一开锁通道）、「操作」（取消 / 查询 / 取事件）。
  • 隐藏：「清单」区（lstBox，编排模式 CONFIGURE/ADD 入口）— setVisible(false)；成员与槽保留。
  • 「输出区」建议保留：解锁推送事件（✓确认/✗失配/软标）与终帧结果当前写入 m_zlrLockerOut，隐藏会丢失业务结果的主要展示位（主 LOG 区只有单行摘要）。如你希望严格按字面把输出区也去掉，回复时注明即可。
  • 连带说明：「操作」区的「开始」依赖清单区已 CONFIGURE——清单区隐藏后「开始」实际不可用，计划将其一并 setEnabled(false)（保留取消/查询/取事件，它们对 UNLOCK_MULTI 流程仍有意义）。
D5 — 布局优化（LOG 区最大化可见）
  • 核心改动：把 m_sccdBox 与 m_zlrBox 分别包进 QScrollArea（widgetResizable=true，无边框透明背景），新的成员 m_sccdScroll / m_zlrScroll 加入 mainLayout。内容超出配给高度时面板内部滚动，不再向下挤压 LOG 区。
  • 显隐切换点跟随调整：L2345/L2359 的 toggle 由操作 m_sccdBox / m_zlrBox 改为操作 scroll 包装器（共 2 处 + 默认隐藏 2 处）。
  • LOG 区保底：m_logDisplay 设 setMinimumHeight(120)，配合 logSplitter stretch=1，任何情况下 LOG 至少可见 ~5 行。
  • 微调：resize(960, 540) → resize(1080, 720)（初始默认给足可视高度）。
  • 不动的部分：Handshake/Function/Tool/Supported/Version 各区、Exporting Area、通信调试面板——需求未涉及，保持原样。

三、需求边界内的处理说明（未越权的部分）

  • 电机 / RGB / 自检 页不动——需求 D1-D4 只点名 UHF / AM / 开锁器。
  • UHF「配置」区（EPC/Bank/Addr/Cnt）保留——需求只点名"控制区域"与"读写区域"；配置区虽主要服务读写，但盘点结果表格"双击填入"也用到 EPC 输入，且隐藏它超出需求字面范围。若也想封禁配置区，回复注明。
  • UHF 标签列表 / 输出区保留——盘点结果展示位，属于"盘点"功能的组成部分。
  • 开启/关闭按钮隐藏的前置依赖：设备侧 POST 后 UHF 自动上电并恢复配置（App_Unlock_Flow §2、Round_098 #9），直接盘点可用；若 UHF 意外关闭，隐藏后无 UI 重新开启——异常场景可通过"通信调试面板"手动发 0x0B/0x01，或后续加恢复开关（见优化建议）。

四、优化建议（可选，默认不做）

  1. 精简开关：在 Tool 区加一个隐藏入口（如长按标题 / 右键菜单「显示全部区域」），随时恢复被精简的区块用于调试——比纯 setVisible(false) 多 ~15 行，不改变默认视图。
  2. 读写封禁与配置区联动：封禁期间配置区的 Bank/Addr/Cnt 输入对用户无意义，可一并灰显，视觉更干净。
  3. 窗口标题栏显示当前展开的设备区（ZLR/SCCD），长会话不用来回滚动确认。

  4. 功能回归：盘点 → 表格出标签；天线检测 / 读状态有回显；解锁（单张 EPC）→ UNLOCK_MULTI 流程正常；停止/取消正常。
  5. 断连复位：拔设备 → ZLR 区收起、UI 复位路径不受 scroll 包装影响。
