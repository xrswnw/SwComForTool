详细执行计划

Task 1: 工程重命名 SwComForTool V1.0 基建

文件: CMakeLists.txt, src/Version.h.in, src/main.cpp, .vscode/launch.json, build/

  • CMakeLists.txt: project(SwComForTool VERSION 1.0.0 LANGUAGES CXX)
  • comforTool → swcomfortool (可执行文件名)
  • MACOSX_BUNDLE_GUI_IDENTIFIER: com.swcomfor.tool
  • build_win.bat / CMakeLists: 移除所有 ComforTool 引用
  • 备份脚本 backup.sh 排除规则保持不变, 但项目名调整: Round_NNN_NNN 路径不动 (历史快照)
  • 窗口标题: "SwComForTool V1.0"
  • 右下角 statusBar 显示版本: 状态栏 (左) + 版本 V1.0 (右), 来自 QStatusBar

Task 2: UI 区域英文命名 UI

文件: src/MainWindow.cpp

  • "握手栏" → "Handshake Area"
  • "功能栏" → "Function Area"
  • "日志区" → "Log Area"
  • "发送区" → "Exporting Area"

Task 3: 握手栏完全重设计 UI+逻辑

文件: src/MainWindow.cpp, src/MainWindow.h

3.1 端口(原 "接口")

  • 标签: "端口:"
  • QComboBox 端口选择: "USB" (默认) / "COM" (暂不启用, 颜色减淡 disabled look)
  • 驱动切换: 改 m_ifaceCombo 数据为字符串 "USB"/"COM", 内部映射 TransportType

3.2 路径(原 "通信接口")

  • 标签: "路径:"
  • QLabel (而非 QComboBox), 默认显示 "VID 5377:PID 5378", 固定宽度 180px 居中
  • 点击 Label → 弹出 QMenu 列出当前 HID 设备 (VID + 描述), 选中后回填 Label
  • 触发枚举 + 显示方式: 与 refreshPorts 一致, 简化显示 "VID XXXX:PID XXXX"

3.3 连接按钮

  • 默认 "连接", 紫色背景 (与现有 openBtn 配色一致)
  • 连接成功后: 文字 "断开", 背景绿色 (QSS 动态切换)
  • 逻辑: onOpen 中翻转 isOpen 状态, 通过 setProperty/style 更新按钮样式

3.4 自动连接逻辑 (Vid 0x5377)

  • 点击连接时: 优先枚举所有 HID, 若有 VID=0x5377 → 直接打开
  • 否则: 取 m_portCombo currentIndex(0) (默认第一个 HID) → 填入但不自动打开

Task 4: 校验描述仅固件更新期间显示 UI

文件: src/MainWindow.cpp

  • 升级控件 (m_progressBar, m_verifyLevelCombo, verifyLabel) 默认 visible=false
  • click "更新固件" → flashControls(true) 中显示 + 升级完成后 endUpgrade() 隐藏
  • 左下角操作描述行 (m_upgradeStatusLabel) 同样仅升级期间可见

Task 5: Log / Exporting 独立边框 UI

文件: src/MainWindow.cpp, stylesheet

  • 现有 Handshake Area 用 QGroupBox 已有边框
  • Log / Exporting 各自包为 QFrame (setFrameShape(QFrame::Box)) 或 QGroupBox
  • 样式: border: 1px solid #c8b8e0; border-radius: 6px 与 Handshake 一致
  • 已有 logProgressBar 嵌入日志区底部 (升级时显示)

Task 6: Log 与 Exporting 位置交换 UI

文件: src/MainWindow.cpp

  • QSplitter Qt::Vertical 当前 addWidget: logWidget, sendWidget
  • 改为: sendWidget (Exporting), logWidget (Log) → Exporting 在上, Log 在下
  • setStretchFactor 同步调整 (Exporting 比例小, Log 比例大)

Task 7: 最下端状态栏 (系统日志 + 版本号) UI

文件: src/MainWindow.cpp

  • 使用 QStatusBar 替代当前 left-bottom 操作描述行
  • 左: 状态消息 (替代 m_funcStatusLabel + 当前 left-bottom)
  • 右: 永久显示 "SwComForTool V1.0" + 编译日期 (永久消息)
  • addPermanentWidget 用于版本号
  • 扫描 USB / 连接状态 等消息用 statusBar()->showMessage(...) (短暂) 或 statusBar 永久 label

Task 8: 底部日志/调试控件清理 UI

左下角现有的 opStatusLabel 已不必要 (被 statusBar 替代). 移除该布局.

  3. Task 3: 握手栏重设计 (端口/路径/连接按钮)
  4. Task 7: 状态栏

风险

  • 工程重命名涉及 build 目录清理 (旧 build 删除)
  • 握手按钮动态样式需 QSS setProperty 才能跨平台
  • 版本号永久显示需要放 statusBar 永久 widget, 不能普通消息 (会被覆盖)
  • 进度条/校验描述默认隐藏, 升级期间才显示
